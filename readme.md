## Description
Coins System, Transfer, Add Coins, Daily

## Features
- User-friendly commands for managing coins.
- Customizable settings through JSON configuration files.
- Simple & Clear codes you can understand them.

## Installation
1. Clone the repository.
2. Install dependencies using:
   ```bash
   npm install
   ```
3. Create a `.env` file with the required environment variables:
   ```
   TOKEN=your_discord_bot_token
   MONGODB_URL=your_mongodb_connection_string
   ```

## Usage
Start the bot using:
```bash
node index.js
```

---
- `JSON/users/dev/id.json`: Add ID Developers here
- `JSON/users/owners/id.json`: Add ID Owners here
- `JSON/daily.json`: Check this file to ctrl the daily
- `JSON/enables.json`: (only developers)
